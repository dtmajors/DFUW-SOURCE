DFUWDeek SFAD extraction

assets/ - Plain or decrypted archive contents, preserving archive paths.
encrypted-unknown/ - Unmodified encrypted payloads with missing keys; NOT usable decoded assets.
manifest.jsonl - Record metadata, output hashes, and any failures.
retry-manifest.jsonl (if present) supersedes failed records in the original manifest.
source.json / result.json - Input identity and verification results.
Java .class files are bytecode, not recovered Java source.
Installed game files were only read; old research outputs were not changed.
