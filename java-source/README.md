# DFUWDeek Java Recovery

`src/` contains the selected readable Java for every available class.
`catalog/` describes the original bytecode, members, dependencies and strings.
`cfr/` preserves the primary output; `alternates/` contains second-engine attempts.
`source-manifest.jsonl` records source choices and hashes; `result.json` lists unresolved cases.
`queue.json` makes interrupted batches resumable. Original class files remain in `../assets/classes/`.

No original names have been invented. A decompiled file is not proof of compilability or equivalent behavior.
